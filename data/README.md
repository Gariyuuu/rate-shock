# Data

Nothing in this directory is committed except `interim/fomc_events_full.csv`
(the assembled event database, small and useful to inspect directly). Everything
else is either a cached third-party download or a derived panel, and both
regenerate from code:

```bash
python scripts/run_analysis.py
```

## Layout

| Directory | Committed? | Contents | How to recreate |
|---|---|---|---|
| `raw/` | **No** (`.gitignore`) | Cached payloads exactly as fetched: the FRBSF surprise workbook, Federal Reserve calendar/press-release HTML, BLS release-archive HTML, FRED CSVs, and the Yahoo Finance price CSV. ~5MB, ~570 files. | Delete and re-run the pipeline; every file is re-fetched from its documented source. |
| `interim/` | Yes | `fomc_events_full.csv` — the full 361-announcement Bauer–Swanson event database before the sample window is applied. | Regenerated by the pipeline. |
| `processed/` | **No** (`.gitignore`) | `analysis_panel.csv`, `event_panel.csv`, `fomc_events.csv`, `response_matrix.csv`, `event_time_paths.csv`. ~4.7MB of derived panels. | Regenerated by the pipeline in seconds. |

## Why raw downloads are cached but not committed

They are third-party payloads (US federal agency HTML and a Federal Reserve Bank
workbook) that re-fetch cleanly, so committing them would add megabytes to the
repository without adding reproducibility. The cache exists so that repeated
local runs are offline and fast, and so the project does not repeatedly hit
public statistical agencies.

Two politeness/robustness details are built into `src/rateshock/http_util.py`:

- Requests carry a **User-Agent with a contact address**, which BLS requires
  (plain `curl` receives HTTP 403).
- **Failed requests are negatively cached.** Probing for the a/b/c suffixes of an
  unscheduled Fed press release produces 404s; without remembering them, every
  pipeline run re-issued those requests and the run took minutes instead of
  seconds.

## Sources

Full provenance — source, frequency, coverage, release timing, transformation
and role for every series — is in [`../docs/DATA_PROVENANCE.md`](../docs/DATA_PROVENANCE.md).

The one input that cannot be re-derived from a public API is the policy-surprise
series itself, which comes from the Federal Reserve Bank of San Francisco's
published update of Bauer & Swanson (2023):

```
https://www.frbsf.org/wp-content/uploads/monetary-policy-surprises-data.xlsx
```

That series currently ends **2023-12-13**, which is what bounds the study's
sample.
